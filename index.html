Part 1: Setting Up the Development Environment

  1. Download Forge 1.21 MDK from official site
  2. Refactor the files to something you want (net.mrnone.examplemod)
  3. Cleanup the ExampleMod class and refactor its name to whatever you want
  4. Go to Gradle.properties and update every updatable details in the lower end of the page
  5. Change the mapping channel to parchment and version to 2024.07.28-1.21
  6. Go to Parchment Documentation and apply the first two changes

Part 2: Creating a Basic Mod

  1. Create a new class 'ModItems' under examplemod/item
  2. Create a DeferredRegister, RegistryObject and a register for the item
    public static final DeferredRegister<Item> ITEMS = DeferredRegister.create(ForgeRegistries.ITEMS, TutorialMod.MOD_ID);
    public static final RegistryObject<Item> ROLLANDRITE = ITEMS.register("rollandrite", () -> new Item(new Item.Properties()));
    public static void register(IEventBus eventBus) { ITEMS.register(eventBus); }
  3. Add
    ModItems.register(modEventBus);
    to the TutorialMod() constructor
  4. add
    if(event.getTabKey() == CreativeModeTabs.INGREDIENTS) { event.accept(ModItems.ROLLANDRITE); }
    to the addCreative() method
  5. Add a folder named ur examplemod under assets, and add 3 folders named models, textures, and lang
  6. Under the models and textures folder, create another folder named item
  7. Under the lang folder, create a file named en_us.json and add the following code
    { "item.tutorialmod.rollandrite": "Rollandrite Ore" }
  8. Under the item folder in the models folder, create a file named rollandrite.json and add the following code
    { "parent": "item/generated",
    "textures": {
    "layer0": "tutorialmod:item/rollandrite" } }
  9. Update the lang file en_us under lang directory
    { "item.tutorialmod.storm_shard": "Storm Shard", "block.tutorialmod.stormshard_block": "Storm Shard Block" }
  10. Add the mod in creative menu tab
  11. Add crafting recipe if needed
  12. That's the basics of creating a simple mod you can now run modded minecraft.

Part 3: Adding a Block

  1. Create a new class 'ModBlocks' under examplemod/block
  2. Create a DeferredRegister, RegistryObject and a register for the block
    public static final DeferredRegister<Block> BLOCKS = DeferredRegister.create(ForgeRegistries.BLOCKS, TutorialMod.MOD_ID);
  3. Register event bus with:
    public static void register(IEventBus eventBus) { BLOCKS.register(eventBus); }
  4. Register event in Examplemod.java file using ModBlocks.register(modEventBus);
  5. Add
    private static <T extends Block> void registerBlockItem(String name, RegistryObject<T> block) {
    ModItems.ITEMS.register(name, () -> new BlockItem(block.get(), new Item.Properties()));}
    to the ModBlocks.java file
  6. Add
    private static <T extends Block> RegistryObject<T> registerBlock(String name, Supplier<T> block) { RegistryObject<T> toReturn = BLOCKS.register(name, block); registerBlockItem(name, toReturn); return toReturn; }
    to the ModBlocks.java file
  7. Add a directory "blockstates" under the resources/assets folder and create the file 'example_block.json'
  8. Add the following code to it
    {
    "variants": {
    "": {
    "model": "tutorialmod:block/example_block"
    }
    }
    }
  9. Add a directory "block" under the resources/assets/models folder and create the file 'example_block.json'
  10. Add the following code to it
    {
    "parent": "block/cube_all",
    "textures": {
    "all": "tutorialmod:block/example_block"
    }
  11. Add a file "stormshard_block.json" to the resources/assets/examplemod/models/item directory
  12. Add the following code to it
    {
    "parent":"tutorialmod:block/stormshard_block"
    }
  13. Add "stormshard_block.png" to the block folder under textures
  14. add
    if(event.getTabKey() == CreativeModeTabs.BUILDING_BLOCKS) { event.accept(ModItems.BLOCK); }
    to the addCreative() method
  15. Update the lang file en_us under lang directory
    { "item.tutorialmod.storm_shard": "Storm Shard", "block.tutorialmod.stormshard_block": "Storm Shard Block" }

Part 6: Adding Mineability

  1. Create a new directory under resources/assets/data/tutorial mod named loot_table and inside that add another directory named blocks. Add the block you want to add mineability to the block itself (eg. Iron Block mined will give you iron block and not iron ingot) to, in this case stormshard_block.json and add the following code
    {
    "type": "minecraft:block",
    "pools": [
    {
    "bonus_rolls": 0.0,
    "conditions": [
    {
    "condition": "minecraft:survives_explosion"
    }
    ],
    "entries": [
    {
    "type": "minecraft:item",
    "name": "tutorialmod:platinum_block"
    }
    ],
    "rolls": 1.0
    }
    ],
    "random_sequence": "tutorialmod:blocks/platinum_block"
    }
  2. For blocks that you want to drop something else, like a block dropping an item, you can add the following code to the block's loot table (eg. Stormshard Block dropping Storm Shard)
    {
    "type": "minecraft:block",
    "pools": [
    {
    "bonus_rolls": 0.0,
    "entries": [
    {
    "type": "minecraft:alternatives",
    "children": [
    {
    "type": "minecraft:item",
    "conditions": [
    {
    "condition": "minecraft:match_tool",
    "predicate": {
    "predicates": {
    "minecraft:enchantments": [
    {
    "enchantments": "minecraft:silk_touch",
    "levels": {
    "min": 1
    }
    }
    ]
    }
    }
    }
    ],
    "name": "tutorialmod:platinumdeepslate__ore"
    },
    {
    "type": "minecraft:item",
    "functions": [
    {
    "enchantment": "minecraft:fortune",
    "formula": "minecraft:ore_drops",
    "function": "minecraft:apply_bonus"
    },
    {
    "function": "minecraft:explosion_decay"
    }
    ],
    "name": "tutorialmod:raw_platinum"
    }
    ]
    }
    ],
    "rolls": 1.0
    }
    ],
    "random_sequence": "tutorialmod:blocks/platinum_deepslate_ore"
    }
  3. Now mineable with the specific tool: Create the directory "tags" under resources/data/minecraft and add a directory named "blocks" and create a file named "mineable/pickaxe.json" and add the following code
    { "replace": false, "values": [ "tutorialmod:stormshard_block", "tutorialmod:voidheart_beacon", "tutorialmod:platinum_block", "tutorialmod:raw_platinum_block", "tutorialmod:platinum_ore", "tutorialmod:platinum_deepslate_ore" ] }
    This is basically saying that these blocks can only be mined by a pickaxe. Now to specifiy which type of pickaxe, we need to create json files with 'needs_diamond_tool' or 'needs_netherite_tool' condition: for example, create needs_diamond_tool.json and needs_iron_tool.json in the same directory and add the following code
    { "replace": false, "values": [ "tutorialmod:platinum_block", "tutorialmod:raw_platinum_block", "tutorialmod:platinum_ore", "tutorialmod:platinum_deepslate_ore" ] }
    This is basically saying that these blocks can only be mined by a diamond pickaxe or better.

Part 7: Adding Advanced Items

  • To Create an Advanced Item, just add the following code:
    public class ChiselItem extends Item {
    private static final Map CHISEL_MAP =
    Map.of(
    Blocks.STONE, Blocks.STONE_BRICKS,
    Blocks.END_STONE, Blocks.END_STONE_BRICKS,
    Blocks.DEEPSLATE, Blocks.DEEPSLATE_BRICKS,
    Blocks.IRON_BLOCK, Blocks.RAW_IRON_BLOCK,
    ModBlocks.PLATINUM_BLOCK.get(), ModBlocks.RAW_PLATINUM_BLOCK.get()

    );

    public ChiselItem(Item.Properties pProperties) {
    super(pProperties);
    }
    @Override
    public InteractionResult useOn(UseOnContext pContext) {
    Level level = pContext.getLevel();
    Block clickedBlock = level.getBlockState(pContext.getClickedPos()).getBlock();

    if(CHISEL_MAP.containsKey(clickedBlock)){
    if(!level.isClientSide()){
    level.setBlockAndUpdate(pContext.getClickedPos(),CHISEL_MAP.get(clickedBlock).defaultBlockState());

    pContext.getItemInHand().hurtAndBreak(1,((ServerLevel) level),((ServerPlayer) pContext.getPlayer()),
    item -> pContext.getPlayer().onEquippedItemBroken(item, EquipmentSlot.MAINHAND));

    level.playSound(null,pContext.getClickedPos(), SoundEvents.GRINDSTONE_USE, SoundSource.BLOCKS, 1.0F, 1.0F);
    }
    }


    return InteractionResult.SUCCESS;
    }
    }
  • Add
    public static final RegistryObject CHISEL = ITEMS.register("chisel", () -> new ChiselItem(new Item.Properties().durability(32)));

Part 8: Adding an Advanced Block

  • Create a new package custom under tutorialmod/block
  • Create a new class with Block at its end, like 'MagicBlock'
  • Add the following Code
    public class MagicBlock extends Block {
    public MagicBlock(Properties properties) {
    super(properties);
    }
    @Override
    protected InteractionResult useWithoutItem(BlockState pState, Level pLevel,
    BlockPos pPos, Player pPlayer, BlockHitResult pHitResult) {
    pLevel.playSound(pPlayer,pPos, SoundEvents.AMETHYST_CLUSTER_PLACE, SoundSource.BLOCKS,1.0f,2.0f);
    return InteractionResult.PASS;
    }
    @Override
    public void stepOn(Level pLevel, BlockPos pPos, BlockState pState, Entity pEntity) {
    super.stepOn(pLevel, pPos, pState, pEntity);
    if(pEntity instanceof ItemEntity itemEntity) {
    if(itemEntity.getItem().getItem() == ModItems.STORM_SHARD.get()){
    itemEntity.setItem(new ItemStack(Items.NETHERITE_INGOT, itemEntity.getItem().getCount()));
    }
    if(itemEntity.getItem().getItem() == ModItems.VOIDHEART_CORE.get()){
    itemEntity.setItem(new ItemStack(Items.NETHERITE_INGOT, itemEntity.getItem().getCount()));
    }
    }
    }
    }
  • Add
    public static final RegistryObject ANCIENT_CRUCIBLE = registerBlock("ancient_crucible", () -> new MagicBlock(BlockBehaviour.Properties.of().strength(2f).requiresCorrectToolForDrops()));
